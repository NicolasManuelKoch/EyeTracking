Gaze Lab v0.4

index.html: interface and styling
app.js: calibration, task and session export
webgazer.js: bundled eye-tracking library with video startup patch

Open files in VS Code to edit. Camera use requires an HTTPS server or localhost; opening index.html directly is insufficient.
For local testing with Python installed: python -m http.server 8000
Then visit http://localhost:8000 in your computer browser.
Phone testing requires HTTPS hosting.
