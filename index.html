Start a session

This prototype measures gaze; it does not diagnose depression. The built-in abstract images test the workflow and are not validated psychological stimuli. Camera processing stays in your browser. No session data is uploaded; model files may download from external providers.

What this version measures

Estimated gaze coordinates, time in each image region, first valid region, tracking gaps, and page visibility interruptions. A missing gaze estimate does not prove that you looked away. Blinks and eyelid openness are not measured yet.
